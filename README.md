# 💳 Smart Expense Tracker

An interactive, sleek personal budget dashboard built with **Streamlit** and **Pandas**. Features a custom glassmorphism dark UI for logging variable expenses, calculating remaining balances, searching activity history, and exporting expense data to CSV.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Frontend / Framework:** Streamlit (Custom HTML/CSS injection)
- **Data Handling:** Pandas
- **APIs & Tools:** Streamlit Session State & Dataframes

---

## 🚀 Key Features
- 📊 **Real-Time Budget Metrics:** Dynamically updates available balance and total monthly spend as expenses are added.
- 🎨 **Custom Dark UI:** Clean glassmorphism aesthetic built using custom CSS injection.
- 🔍 **Search & Filter:** Search logged expenses instantly by item name or category.
- 📥 **CSV Export:** Export your logged expense history with one click.
- 📱 **Sidebar Control Center:** Easily configure fixed monthly bills and set dynamic target budgets.
